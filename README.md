# GD Sync (Google Drive Sync for Obsidian)

데스크톱 및 모바일 기기에서 옵시디언(Obsidian) 보관함을 Google Drive와 동기화하세요.

## ✨ 주요 기능

- **양방향 동기화**: 로컬 보관함과 Google Drive 간의 노트를 동기화된 상태로 유지합니다.
- **자동 동기화**: 설정된 지연 시간이 지나면 변경 사항을 자동으로 업로드합니다.
- **백그라운드 동기화**: 백그라운드에서 주기적으로 원격의 변경 사항을 확인합니다.
- **충돌 해결**: 충돌 발생 시 처리 방법(로컬 유지, 원격 유지, 둘 다 유지 또는 병합)을 선택할 수 있습니다.
- **모바일 지원**: 옵시디언의 데스크톱 및 모바일(iOS/Android) 버전 모두에서 동작하도록 설계되었습니다.
- **보안성**: 자격 증명을 노출하지 않고 안전한 인증을 위해 PKCE가 포함된 OAuth 2.0을 사용합니다.
- **선택적 동기화**: 보관함과 동기화할 Google Drive의 특정 폴더를 선택할 수 있습니다.
- **동기화 기록**: 최근 동기화 로그를 확인할 수 있습니다.

## 🚀 시작하기

### 1. 설치 방법

#### BRAT을 통한 설치 (베타 버전 권장)
1. [Obsidian42 - BRAT](https://github.com/TfTHacker/obsidian42-brat) 플러그인을 설치합니다.
2. **Settings(설정)** -> **BRAT** -> **Add Beta plugin**을 엽니다.
3. 저장소 URL을 입력합니다: `https://github.com/GomPam/Obsidian-GD-Sync`
4. **Add Plugin**을 클릭합니다.

### 2. 설정 방법

1. **Settings(설정)** -> **GD Sync**로 이동합니다.
2. Google 계정으로 인증하기 위해 **Connect(연결)** 버튼을 클릭합니다.
3. 연결되면 **Select Folder(폴더 선택)** 버튼을 클릭하여 보관함을 동기화할 Google Drive 내 폴더를 선택하거나 생성합니다.
4. (선택 사항) 설정에서 **Auto-Upload Delay(자동 업로드 지연 시간)** 및 **Background Sync Interval(백그라운드 동기화 간격)**을 조정합니다.

## ⚠️ 중요 참고 사항 및 모범 사례

- **보관함 백업**: GD Sync는 안정적으로 동작하도록 설계되었지만, 동기화 도구를 사용하기 전에 항상 노트의 별도 백업을 만들어 두는 것이 좋습니다.
- **동시 편집 피하기**: 충돌을 최소화하기 위해 두 기기에서 동일한 파일을 동시에 편집하지 않도록 주의하세요.
- **첫 동기화**: 보관함의 크기에 따라 첫 번째 동기화(전체 동기화)에 시간이 다소 소요될 수 있습니다.

## 🛠 문제 해결

- **인증 만료**: 인증 오류가 표시되면 설정에서 **Reconnect(다시 연결)** 버튼을 클릭하세요.
- **수동 동기화**: 리본 아이콘(구름 모양)이나 명령어 팔레트를 사용하여 수동으로 전체 동기화를 실행할 수 있습니다.
- **기록 확인**: **View Sync History(동기화 기록 보기)** 명령을 사용하여 최근에 동기화된 항목을 확인하고 오류가 있는지 살펴보세요.
